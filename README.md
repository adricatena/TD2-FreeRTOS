# FreeRTOS con ESP32

Repositorio de trabajos prácticos para la materia **Técnicas Digitales 2** de la carrera de **Ingeniería Electrónica** en la **Universidad Tecnológica Nacional (UTN)**.

El objetivo es introducir el uso de **FreeRTOS** sobre placas **ESP32** mediante cinco proyectos pequeños y progresivos.

## Proyectos

1. Creación y ejecución de tareas.
2. Uso de retardos y temporización.
3. Comunicación entre tareas.
4. Sincronización con semáforos y mutex.
5. Integración de tareas con periféricos del ESP32.

## Requisitos

- Placa ESP32.
- PlatformIO.
- Soporte para ESP32 instalado.
- Conocimientos básicos de C/C++ y sistemas embebidos.

Cada proyecto incluye su código fuente y las indicaciones necesarias para compilarlo y cargarlo en la placa.
